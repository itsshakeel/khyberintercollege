# Khyber Inter College Kohat — Demo Website

A modern, fully responsive demo website for **Khyber Inter College Kohat**
(HFF8+4QP, Road, Kohat · 0333 9607099), built to showcase a premium design
for the client.

## Pages / Sections

- Sticky navbar with mobile menu
- Hero with admissions notice card
- Animated stats counters
- About + Principal's message
- Why Choose Us features
- Programs: Pre-Medical, Pre-Engineering, ICS, I.Com, FA
- Admissions: 4-step process, documents, scholarships, call-back form
- Campus gallery
- Testimonials slider
- Notice board, contact cards, embedded Google Map
- Footer

## Tech

Pure **HTML + CSS + JavaScript** — no build step, no dependencies.
Deploy anywhere static sites work (Vercel, Netlify, GitHub Pages).

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## Deploy on Vercel

1. Import this repo in Vercel (or run `vercel` in this folder)
2. No build command needed — the site is static
3. Done 🎉
